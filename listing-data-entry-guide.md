# Listing Data Entry Guide

Use `/assets/data/listings-intake-template.csv` for real inventory collection.

Required fields:

- `listing_id`
- `type` (`Sale` or `Lease`)
- `status`
- `title`
- `project`
- `projectSlug`
- `projectUrl`
- `location`
- `bhk`
- `size`
- `floor`
- `furnishing`
- `availability`
- `price`
- `priceNote`
- `image`
- `gallery_1`
- `gallery_2`
- `gallery_3`
- `detailUrl`
- `legacyUrl`
- `description`
- `highlight_1` to `highlight_4`

Do not enter private owner details, exact flat number, keys location, negotiation notes or personal phone numbers into public listing data.
